# DNA Marker Data

A curated dataset of commercial DNA size markers / ladders used in agarose gel electrophoresis.

Each entry includes the product name, supplier, official product page URL, and the full band profile (fragment length, relative mass, and whether the band is a reference/hidden band).

## Data Schema (products.json)

```json
{
  "<Supplier Name>": {
    "domain": "<official domain>",
    "ladders": [
      {
        "name": "<product name>",
        "preferred_units": "bp | kb",
        "url": "<product page URL>",
        "fragments": [
          {
            "length": <int, base pairs>,
            "mass": <number, relative band intensity>,
            "format": "bold | hidden | <empty>"
          }
        ]
      }
    ]
  }
}
```

### Field meanings

| Field | Meaning |
|-------|---------|
| `length` | Fragment length in base pairs (bp) |
| `mass` | Relative mass/intensity of the band — larger value = thicker/brighter band |
| `format` | Band display style: `bold` = reference band (emphasised on the gel); `hidden` = defined but not shown; empty = normal |
| `preferred_units` | Display unit the supplier recommends (`bp` or `kb`) |
